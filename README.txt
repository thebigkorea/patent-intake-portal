# 특허 상담·출원 접수 포털 시안

## 구성
- index.html
- style.css
- script.js

## 현재 포함 기능
- 외부 고객용 랜딩페이지
- 특허 가능성 사전검토 / 출원 접수 진입
- 단계형 11문항 입력
- 필수값 검증
- 브라우저 localStorage 자동 임시저장
- 첨부파일 UI
- 제출 전 최종 확인
- 접수번호 데모 발급
- 모바일 반응형

## 아직 실제 운영 전 연결할 것
1. Google Apps Script 또는 별도 서버 API
2. Google Sheet / DB 저장
3. 첨부파일 실제 업로드 저장
4. 접수 완료 이메일/문자/카카오 알림
5. 관리자 접수현황 화면
6. 개인정보처리방침 / 이용약관 / 변리사 및 사업자 정보
7. SSL, 접근권한, 관리자 로그인, 로그 기록 등 보안
8. 진행상황 조회 기능
