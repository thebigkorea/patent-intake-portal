특허상담 관리자 상세검색 V3

교체 대상
1. admin.html
2. admin.css
3. admin.js
4. Code.gs -> Code.gs.txt 내용으로 전체 교체

중요:
- Code.gs를 교체한 뒤 Apps Script에서 '배포 관리' > 기존 웹 앱 수정 > 새 버전 배포
- ADMIN_KEY 스크립트 속성은 그대로 유지됩니다.
- 웹앱 URL도 기존 주소 유지 가능

추가된 검색 조건
- 접수 시작일 / 종료일
- 서비스구분
- 진행상태
- 담당자
- 신청자
- 회사/소속
- 연락처
- 이메일
- 발명의 명칭
- 기술 분야
- 공개 여부
- 통합 키워드
- 최신/오래된/최근수정/신청자 가나다 정렬

통합 키워드는 다음 내용을 함께 검색:
접수번호, 신청자, 회사, 연락처, 이메일, 발명명칭, 기술분야,
기존방식 문제점, 해결과제, 구현방법, 기대효과, 핵심차별점,
공개 참고사항, 담당자, 관리자 메모, 서비스, 진행상태

또한 관리자 저장 시 실제 변경이 없으면 진행이력을 추가하지 않도록 개선했습니다.
