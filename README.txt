특허상담 접수 포털 V5

수정사항
- 고객 연락처: 010 고정 해제. 02, 031, 042, 010 등 직접 입력 가능
- 전화번호 3칸 형식 유지: [앞자리]-[중간]-[끝자리]
- 사무실 전화도 허용: 앞자리 2~4자리, 중간 3~4자리, 끝자리 4자리
- 관리자 상세검색 연락처도 동일한 3칸 형식으로 변경
- 기존 저장값은 010-1234-5678 / 02-1234-5678 형태로 그대로 저장
- 이메일 선택입력 방식 유지
