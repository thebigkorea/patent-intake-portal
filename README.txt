고객 신청화면 V5.1

변경:
- 연락처 첫 칸에 010이 실제 기본값으로 들어감. 사용자가 02, 031, 042 등으로 수정 가능.
- 이메일 도메인 선택 폭 확대.
- 첨부 가능 파일/용량/권장 자료 상세 설명.
- JPG/JPEG/PNG/PDF, 최대 3개, 파일당 5MB 검증.
- 초과 용량 및 기타 파일은 회사 상담 이메일로 별도 전송하라는 안내 문구 추가.

중요:
현재 이 파일 선택 기능은 브라우저 단계에서 파일 종류/크기를 검사하고 파일명을 표시하는 기능입니다.
Google Drive로 실제 업로드하는 기능은 아직 Code.gs 백엔드 연결이 필요합니다.
